# Calculator

A working calculator web app built with HTML, CSS and JavaScript.

## Features
- Basic operations: add, subtract, multiply and divide
- Clear and delete buttons
- Clean layout with a display screen

## Tech used
- HTML
- CSS
- JavaScript

## Live demo
https://milansah17.github.io/calculator/

## How to run locally
1. Download or clone this repository.
2. Open `index.html` in any browser.

## What I learned
- Handling button clicks with `onclick` and JavaScript functions
- Updating the display dynamically with the DOM
- Building a calculator layout with CSS
